# 发音来源与缓存

0.0.1 的 117,902 个核心词按 `entry_id` 随包提供离线录音，两版共用。真人录音优先使用已固定的 436 条 Commons 文件；其余核心词由锁定版本的 eSpeak NG 生成 Ogg Opus。完整版的非核心词可由客户端按需在线朗读并缓存；全部词条随包音频留给 0.0.2。

| 路径 | 当前项目状态 | 使用方式 |
| --- | --- | --- |
| Wikimedia Commons | 436 条固定录音；另有按需缓存参考工具 | 随包署名在 `audio-sources.json`。新增声音需通过 Commons Action API 复核作者、许可、来源页与文件哈希。未经复核的候选链接不进入离线包。 |
| eSpeak NG + Opus | 固定版本、声线和编码参数在 `audio-tools.lock.json` | 为缺少真人录音的核心词生成可续跑的离线文件；`kind=synthetic`，异常字符拼读另用 `style` 标记。运行时设备 TTS 不计入随包覆盖。 |
| 设备 TTS | 客户端可选后备能力 | 用系统提供的语音播放，标注为合成语音；本仓库不捆绑设备声音。 |
| Azure、有道等在线服务 | 0.0.1 未接入 | 若未来实现，应由客户端管理密钥、额度、服务条款与缓存规则；不能把第三方网页直链当作项目承诺的免费公共 API，也不能未经授权批量制作分发包。 |

缓存键至少包含文本、地区、提供方、音色/文件、语速和词典版本。缓存与只读词典、用户单词本分开，客户端提供清理入口。词性或地区没有证据时保持未知，不把某个拼写的录音强配所有义项。

本仓库的参考命令：`python3 -m leximeet_dictionary cache-audio --db build/base/dictionary.sqlite --cache audio-cache --region en-US bank`。该命令用于验证 Commons 按需缓存逻辑；桌面端和插件端需在各自项目中实现播放界面。
