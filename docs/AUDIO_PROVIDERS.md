# 发音来源与缓存

0.0.1 的新版目标是核心版与完整版都**逐词附离线音频**，用户点击即可播放，不依赖网络。当前已取得 436 条 OGG；旧的带发音/无音频候选不符合新目标。以下在线提供方仅作为额外口音、音色或后续缓存的可选来源，不能替代随包覆盖。

| 路径 | 当前项目状态 | 使用方式 |
| --- | --- | --- |
| Wikimedia Commons | 已取得 436 条固定录音，也有按需缓存参考工具 | 先查 `audio/manifest.json`；如用户另需其他声音，可根据 `audio_candidates` 线索向 Commons Action API 复核作者、许可、来源页与文件哈希，再下载到独立缓存。未经复核的链接不是可分发录音。 |
| 经固定版本语音引擎生成的音频 | 尚未选定和构建 | 用于补齐缺少真人录音的词条；先核对引擎与语音模型许可、生成语音的再分发条件及发音质量，再保存逐文件哈希和来源。运行时设备 TTS 不计入随包音频。 |
| 设备 TTS | 客户端可选后备能力 | 用系统提供的语音播放，标注为合成语音；本仓库不捆绑设备声音。 |
| Azure、有道等在线服务 | 0.0.1 未接入 | 若未来实现，应由客户端管理密钥、额度、服务条款与缓存规则；不能把第三方网页直链当作项目承诺的免费公共 API，也不能未经授权批量制作分发包。 |

缓存键至少包含文本、地区、提供方、音色/文件、语速和词典版本。缓存与只读词典、用户单词本分开，客户端提供清理入口。词性或地区没有证据时保持未知，不把某个拼写的录音强配所有义项。

本仓库的参考命令：`python3 -m leximeet_dictionary cache-audio --db build/v0.0.1-final/dictionary.sqlite --cache audio-cache --region en-US bank`。该命令用于验证 Commons 按需缓存逻辑；桌面端和插件端需在各自项目中实现播放界面。
