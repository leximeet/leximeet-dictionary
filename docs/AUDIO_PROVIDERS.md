# 发音来源与缓存

0.0.1 的查词完全离线。带发音版附 436 条高频 OGG；无音频版不附录音。词遇客户端应只在用户点击朗读时取额外音频，在线失败不影响词卡。

| 路径 | 当前项目状态 | 使用方式 |
| --- | --- | --- |
| Wikimedia Commons | 已实现固定录音包和按需缓存工具 | 先查 `audio/manifest.json`；没有离线文件时，使用 `audio_candidates` 线索向 Commons Action API 复核作者、许可、来源页与文件哈希，再下载到客户端独立缓存。未经复核的链接不是可分发录音。 |
| 设备 TTS | 客户端可选后备能力 | 用系统提供的语音播放，标注为合成语音；本仓库不捆绑设备声音。 |
| Azure、有道等在线服务 | 0.0.1 未接入 | 若未来实现，应由客户端管理密钥、额度、服务条款与缓存规则；不能把第三方网页直链当作项目承诺的免费公共 API。 |

缓存键至少包含文本、地区、提供方、音色/文件、语速和词典版本。缓存与只读词典、用户单词本分开，客户端提供清理入口。词性或地区没有证据时保持未知，不把某个拼写的录音强配所有义项。

本仓库的参考命令：`python3 -m leximeet_dictionary cache-audio --db build/v0.0.1-final/dictionary.sqlite --cache audio-cache --region en-US bank`。该命令用于验证 Commons 按需缓存逻辑；桌面端和插件端需在各自项目中实现播放界面。
