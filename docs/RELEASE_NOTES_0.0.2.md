# LexiMeet Dictionary 0.0.2 Core

核心版提供 117,902 条完整词卡和逐词离线音频，并加入 23 个考试词书与专业目录。现有短助记和 DictionaryByGPT4 学习文章合计覆盖 84,491 个词；其余词仍可正常查词、按词书学习和朗读。

下载 `release.json` 及其中 `editions.core.assets`，按清单校验后安装；与 0.0.1 同名同哈希的音频分片可以复用。升级说明见 [客户端接入协议](https://github.com/leximeet/leximeet-dictionary/blob/v0.0.2/docs/CLIENT_CONTRACT_0.0.2.md)。DictionaryByGPT4 文章标为 `ai-unreviewed`，应在客户端折叠显示。来源和许可见词包内 `DATA-LICENSE.md` 与 `notice-*`。
