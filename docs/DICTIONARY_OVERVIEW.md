# 数据来源与版本总览

最新交付为 [0.0.3 Release](https://github.com/leximeet/leximeet-dictionary/releases/tag/v0.0.3)：五种组合按词卡和音频分层下载，安装时建立索引。下载大小与接入方式见[词包说明](PACKAGES_0.0.3.md)。以下区分数据底座、学习层与旧版资产。

## 0.0.1 数据底座

以下数字来自 0.0.1 的固定输入，并非上游最新版横评。一个“词条”指一个独立 `entry_id`；ECDICT 原始 CSV 的“行”和词遇合并后的“词条”口径不同。

| 来源 | 进入词遇的内容 | 固定输入数量 |
| --- | --- | ---: |
| open-dictionary v2.0 | 策展词卡、中文学习解释、例句、词形、IPA；同版 audit 补英文原义及标签 | 84,212 词条、241,427 义项 |
| Wiktionary / Kaikki | 主词源缺少的高频冠词、连词义项 | 34 词、161 条独立英文义项 |
| ECDICT | 中文与缺词回退、考试标签、历史频率 | 原始 770,611 行；合并后新增 726,880 词条 |
| CMUdict | 美式 ARPABET 音素 | 87,412 词条含该记法 |
| Open English WordNet | 可独立查询的概念网络 | 107,519 synset |
| Wikimedia Commons | 逐文件署名的核心词真人离线录音 | 436 条 OGG |
| eSpeak NG + Opus | 其余核心词的本地合成离线录音 | 117,466 条核心词；非核心词音频等核心结构稳定后规划 |
| 词遇审校层 | 对抽样发现的歧义提供有证据的中文显示，保留原字段 | 8 词头、6 处原字段修订 |

最终合并结果为 **811,092 词条、241,588 义项**，其中 768,739 词条有 ECDICT 词条级中文回退；14,942 词条有 ECDICT 显式考试标签。qwerty-learner 和 DictionaryByGPT4 未进入 0.0.1 底座，自 0.0.2 起作为独立学习层进入核心词包。

## 0.0.2 学习层与 0.0.3 交付

| 来源或版本 | 新增内容 |
| --- | --- |
| qwerty-learner | 固定词书的词头、学习顺序、归属、逐书补充译文及原始英美音标 |
| DictionaryByGPT4 | 独立的 AI 学习文章候选，保留来源与待复核状态 |
| 0.0.2 核心版 | 23 个考试／专业目录；84,491 个核心词有助记，33,411 个暂无助记 |
| 0.0.3 分层词包 | lite 26,417 词、core 117,902 词、full-text 811,092 词；lite／core 分别可选无音频或逐词有声 |

0.0.3 保留入选核心词的完整词卡和已有学习内容，通过压缩与共享差量减少下载大小。非核心词的学习内容与全词音频见[开发路线](ROADMAP.md)。

## 相比单一数据源的增量

| 维度 | open-dictionary v2.0 | ECDICT | 词遇 0.0.1 |
| --- | --- | --- | --- |
| 词义展示 | 学习者向逐义词卡 | 单行词条级翻译 | 保留逐义词卡，缺词时给出明确标识的词条级回退 |
| 覆盖 | 84,212 策展词条 | 770,611 原始行 | 811,092 合并词条；不把新增数量误称人工校对量 |
| 标签 | 义项领域、用法 | 考试声称、频率 | 保留两种作用域，避免把考试词表误贴到具体义项 |
| 发音 | IPA、待核权音频线索 | 旧式音标 | IPA/ARPABET 分开；两版共有 117,902 条核心词离线音频，非核心词可在线朗读 |
| 交付 | 上游格式 | CSV | 完整 JSONL、可重组的 SQLite 分片、共享音频分片及哈希清单 |

词遇的明确优势是**多来源组合、保留来源边界、可校验的多端安装包**。ECDICT-only 词条多数仍没有逐义项双语解释；WordNet 概念尚未自动对齐主词义。

## 0.0.1 历史详情与词包

| 本地文件 | 用途 |
| --- | --- |
| `dist/reports/leximeet-dictionary-0.0.1-details.md` | 811,092 行全量词头与释义表；逐义中文、词遇审校显示、ECDICT 词条级回退分别列出。约 196 MB，仅供检索和审阅，不随安装包分发。 |
| 核心版 `core` | 117,902 条完整词卡与 117,902 条离线音频；正式 Release 资产合计 357,719,296 字节（约 341 MiB），供端侧内置 |
| 完整版 `full` | 811,092 条完整词卡，共享核心词的 117,902 条离线音频；SQLite 切为 5 片；正式 Release 资产合计 1,743,717,043 字节（约 1,663 MiB），供用户主动下载 |

以上下载大小为 0.0.1 各版 `assets` 的总和，另需获取 `release.json`；完整版已包含共享的核心资产，升级时无需重复下载。准确 SHA-256 与分片清单以 [v0.0.1 Release](https://github.com/leximeet/leximeet-dictionary/releases/tag/v0.0.1) 的 `release.json` 为准，单个资产不超过 256 MiB。新项目优先使用 [0.0.3 分层词包](PACKAGES_0.0.3.md)。
