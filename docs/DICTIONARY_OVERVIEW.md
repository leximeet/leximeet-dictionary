# 0.0.1 数据总览与上游对比

以下数字来自当前固定输入的本地候选，并非上游最新版横评。一个“词条”指一个独立 `entry_id`；ECDICT 原始 CSV 的“行”和词遇合并后的“词条”口径不同。

| 来源 | 进入词遇的内容 | 本地数量 |
| --- | --- | ---: |
| open-dictionary v2.0 | 策展词卡、中文学习解释、例句、词形、IPA；同版 audit 补英文原义及标签 | 84,212 词条、241,427 义项 |
| Wiktionary / Kaikki | 主词源缺少的高频冠词、连词义项 | 34 词、161 条独立英文义项 |
| ECDICT | 中文与缺词回退、考试标签、历史频率 | 原始 770,611 行；合并后新增 726,880 词条 |
| CMUdict | 美式 ARPABET 音素 | 87,412 词条含该记法 |
| Open English WordNet | 可独立查询的概念网络 | 107,519 synset |
| Wikimedia Commons | 可选高频离线录音，逐文件署名 | 436 条 OGG |
| 词遇审校层 | 对抽样发现的歧义提供有证据的中文显示，保留原字段 | 8 词头、6 处原字段修订 |

最终合并结果为 **811,092 词条、241,588 义项**，其中 768,739 词条有 ECDICT 词条级中文回退；14,942 词条有 ECDICT 显式考试标签。qwerty-learner 和 DictionaryByGPT4 当前没有内容进入词包。

## 相比单一数据源的增量

| 维度 | open-dictionary v2.0 | ECDICT | 词遇 0.0.1 |
| --- | --- | --- | --- |
| 词义展示 | 学习者向逐义词卡 | 单行词条级翻译 | 保留逐义词卡，缺词时给出明确标识的词条级回退 |
| 覆盖 | 84,212 策展词条 | 770,611 原始行 | 811,092 合并词条；不把新增数量误称人工校对量 |
| 标签 | 义项领域、用法 | 考试声称、频率 | 保留两种作用域，避免把考试词表误贴到具体义项 |
| 发音 | IPA、待核权音频线索 | 旧式音标 | IPA/ARPABET 分开；可选 436 条离线录音，其余按需查询 |
| 交付 | 上游格式 | CSV | SQLite、JSONL、5,000 词核心包、无音频包、带音频包及校验清单 |

词遇的明确优势是**多来源组合、保留来源边界、可校验的多端安装包**。ECDICT-only 词条多数仍没有逐义项双语解释；WordNet 概念尚未自动对齐主词义。
